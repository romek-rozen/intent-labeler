Recommended elements

Use
  • Comparison table - Allow users to quickly compare price, weight, and cushion level across different models.
  • Pros/Cons list - Give a balanced view of each shoe's performance as seen in r05.
  • Buyer's quiz/checklist - Help users determine if they need stability or neutral shoes based on their gait.
Avoid
  • Generic 'Top 10' list without categories - Running shoes are highly specialized; a generic list doesn't help a user distinguish between a marathon shoe and a trail shoe.
