## Use
- Interactive form fields: Allow users to input custom loan values (principal, years, interest rate).
- Real-time result display: Show the calculated monthly installment and total interest paid instantly.
- Toggle for installment type: Let users switch between equal (annuity) and decreasing installments.
- Creditworthiness check option: Provide a secondary calculation for maximum eligible loan amount based on income.

## Avoid
- Long introductory essays: Users are looking for a tool; excessive text before the calculator frustrates the task-oriented user.
- Static examples only: Pre-calculated tables for specific amounts (e.g., 'Rate for 300k') are less useful than a dynamic calculator because users rarely have those exact numbers.
